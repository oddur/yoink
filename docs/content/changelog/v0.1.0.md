### New

- Rust container deploy CLI with TUI at tools/yoink
- Multi-service deploy, replicas, hooks, staging groundwork
- Kamal-inspired exec/logs/version CLI commands
- Embedded PTY shell: k9s-style drop-into-container
- Debug sidecar: alpine container in target's pid+net ns
- TUI polish: breadcrumbs, state colors, help overlay
- K9s-style header (tabs + breadcrumb in a bordered block)
- Inline gauges + sparklines in dashboard, real LineGauge/Sparkline in HostDetail
- / filter on Dashboard, Hosts, HostDetail, Services, ServiceDetail
- `shell` and `debug` CLI subcommands (terminal-side PTY)
- Restart, validate, lock status/release, diff, dry-run, completions
- Container detail TUI view (key `i`)
- Rich container-detail view + embedded log tail
- Magical `local` host: TUI auto-detects local docker socket
- Image column in HostDetail's container table
- `kill` and `pull` CLI subcommands
- Deploy audit labels + `yoink history <service>`
- K key in TUI: SIGKILL container with confirmation modal
- Emit per-layer pull progress at info level
- `yoink top`: CPU%-sorted snapshot
- Toast notifications for docker events in TUI header
- `yoink tui --mouse` opt-in mouse support
- System info in HostDetail summary panel
- `yoink networks` and `yoink volumes` CLI commands
- Per-service docker networks for tier isolation
- Drift column on TUI Dashboard (Phase A)
- TUI reconcile (Phase B): `U` key triggers `yoink up` for one service
- Selectable Dashboard rows + lock-image auto-pull
- Streaming reconcile progress modal
- Healthcheck-failed reconcile streams the dead container's log tail
- `y` to yank logs to system clipboard via OSC-52
- `yoink dump`: diagnostics JSON for paste-into-LLM
- Tier networks, depends_on graph, faster reconcile, TUI status table
- Support image digests (image@sha256:...) alongside tags
