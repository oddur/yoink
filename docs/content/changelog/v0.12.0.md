### New

- **proxy:** Emit Docker HEALTHCHECK on the synthesized yoink-proxy
- **tui:** Refresh secrets cache after a successful in-TUI edit
- Drift modal, `--plan`/`--watch`/`--here`, replica-aware shell + logs
- **secrets:** Multi-identity keys dir at ~/.config/yoink/keys/
- Yoink doctor 🩺: diagnose deploy-blockers before `yoink up`
- **pf:** Port-forward published service ports via ssh -L
- **add:** `yoink add <name>`: fetch+render templates from GitHub
- **up:** Plain `yoink up` works for pure-build, mixed, and pure-registry configs
- **run:** Expose `devices:` for hardware passthrough
- End-to-end backup story: rustfs + restic-backups + postgres PITR
- **proxy:** `proxy.xcaddy:`: compile caddy with plugins, no registry
- **config:** Expand `${VAR}` env references in YAML at load time
- **preflight:** `--wait <DURATION>` polls for docker readiness

### Fixed

- **sealed:** Handle multi-line quoted values in `secrets seal` / `edit`
